# Godot 4.7 Nintendo 3DS

Backend experimental para exportação de projetos Godot 4.7
para Nintendo 3DS usando devkitARM/devkitPro.

## Host

macOS.

## Target

Nintendo 3DS.

## Toolchain

- devkitARM
- libctru
- citro3d
- arm-none-eabi-g++

## Saídas

- ELF
- 3DSX
- CIA

O Editor Godot continua executando no macOS.
