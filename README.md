# 2dog fork of the Godot Engine

This is a fork of the Godot Engine that's used by [2dog](https://2dog.dev) to build specific `libgodot` variants suited for embedding in .NET

Generally, this repo can serve as a source for reference fixes in upstream Godot, but since parts of it are AI-maintained / prototyped (in particular: experimental features), we decided to maintain a separate fork.

Each 2dog branch is for a specific stable branch of Godot:
- 2dog-4.7.2 <-> Godot 4.7.2-stable

Godot is MIT licensed, as is this repository.
